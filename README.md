# 英语口语小达人 🦜

给小朋友练口语的应用。素材来自 `常用口语.xls`（999 句），自动分成 50 关，每关 20 句。

同一套内容有两个版本：

| 版本 | 目录 | 怎么用 |
|---|---|---|
| 网页版 | 根目录 | 电脑浏览器 / 手机浏览器（需 HTTPS，识别走 Web Speech API） |
| **小程序版** | `miniprogram/` | **微信里直接打开，朗读和识别用微信官方插件，最稳** ← 推荐 |

小程序版的部署步骤见 **[README-miniprogram.md](README-miniprogram.md)**。

## 怎么用（电脑）

1. 双击 `启动练习.bat`（会用默认浏览器打开 http://127.0.0.1:8899/index.html）
2. 选一关 → 点 **🔊 听一听** → 点 **🎤 开始跟读** → 读完后自动打分

> 建议用 **Edge 或 Chrome**。第一次点「开始跟读」时浏览器会问是否允许麦克风，点「允许」。

## 怎么用（手机 / 发到微信）

1. 双击 `手机访问.bat` → 等 5–20 秒，窗口里会显示一个 `https://xxxx.trycloudflare.com/index.html` 链接
2. 链接已自动复制到剪贴板 → 粘贴到微信发出去
3. 手机点开 → **右上角 ⋯ → 在浏览器打开** → 允许麦克风 → 开始练

注意事项：

- 微信内置浏览器 **不支持** 语音识别，必须「在浏览器打开」；页面里会自动弹提示教怎么点
- iPhone 用 **Safari** 打开效果最好（识别走苹果服务器，国内可用）
- Android 的 Chrome 识别要连 Google，国内可能连不上，失败时页面会自动切到「家长手动打分」
- 这个临时链接 **关掉窗口就失效**，且电脑关机 / 睡眠后手机的链接也打不开；每次重新运行会换一个新地址
- 想要「永远不变的链接」（关电脑也能用），需要部署到 GitHub Pages / Netlify / 腾讯云 COS 这类静态托管，见下面

## 部署成永久链接

整个文件夹就是纯静态站点，丢到任何静态托管即可，无需后端：

- **GitHub Pages**：新建仓库 → 上传本文件夹内容 → Settings → Pages → Source 选 main 分支根目录 → 得到 `https://用户名.github.io/仓库名/`
- **Netlify / Vercel**：把文件夹拖进网页即可，几秒出 HTTPS 链接
- 国内访问更稳的话用 **腾讯云 COS + CDN** 或 **阿里云 OSS**，记得开 HTTPS

> 必须 HTTPS，否则手机浏览器不允许用麦克风。

## 功能

- **看**：大字号英文 + 中文意思（可一键隐藏中文，只看英文读）
- **听**：标准美式发音，可调语速（0.5x～1.3x），还有 🐢 慢速按钮
- **录**：🔴 录音对比 —— 录下孩子的声音，跟标准音来回对比（不依赖语音识别，安卓也能用）
- **读**：点麦克风跟读，实时显示识别到的文字
- **评**：逐词对比打分（绿=读对，黄=接近，红=没读对/漏读），给出 0–100 分和星星
- **练**：错题本（低于 75 分自动收录）、我的收藏、随机挑战
- **记**：分数、收藏、关卡进度都存在浏览器本地（localStorage），下次打开还在

## 打分说明

用词级对齐算法（编辑距离 + 同音词识别），按词权重计算：
- 实词读错扣分多，a / the / to 这类虚词漏读扣分少
- `see / sea`、`two / to / too`、`right / write` 等同音词视为读对
- 数字与英文单词等价（`60` = `sixty`）
- 多读的词扣少量分，不影响主要得分

## 换素材

把新的 xls 路径填到 `build_data.py` 里，运行 `python build_data.py` 即可重新生成 `data/phrases.js`。
（默认读取单列格式：`1. English. 中文意思`）

## 常见问题

- **提示「语音识别需要联网」**：Chrome 的识别走 Google 服务器，国内网络可能不通。改用 **Edge** 通常可以。
- **没有声音**：设置里换个「朗读声音」；Windows 没有英语语音包时，去「设置 → 时间和语言 → 语音」添加英语（美国）。
- **麦克风没反应**：点地址栏的锁图标 → 麦克风 → 允许，然后刷新页面。
